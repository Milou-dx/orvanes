# Sécurité

Orvanes donne un terminal et l'accès aux fichiers de la machine : une faille peut être grave.

Pour signaler une faille, n'ouvrez pas d'issue publique. Utilisez « Report a vulnerability » dans l'onglet Security du dépôt [Milou-dx/orvanes](https://github.com/Milou-dx/orvanes/security). Indiquez la version, les étapes pour reproduire et l'impact.

Seule la dernière version de la branche `master` reçoit des correctifs.
